01 · Codex

Objetivo

Generar studio/management/commands/seed_ascend_branding.py con update_or_create, transacciones, validación de archivos y modo dry-run.

Comando

python manage.py seed_ascend_branding

Carpeta

BRANDING

Seguridad

No eliminar ni sobrescribir silenciosamente data ajena.

Prompt para Codex

Lee este HTML completo y usa el bloque JSON con id ascend-seed-manifest como fuente de verdad. Genera un comando Django idempotente, compatible con studio/models.py, que resuelva workspace y usuario, cargue archivos desde BRANDING, cree las relaciones y soporte --dry-run.

02 · Brand Kit

Ascend

Ascend es una plataforma de inteligencia artificial orientada al sector ecommerce. Su propósito es acelerar el desarrollo de aplicaciones, automatizaciones y herramientas que mejoren las operaciones comerciales, financieras, de marketing, logística, atención al cliente, análisis y gestión empresarial. Ascend combina dirección creativa, generación de contenido, automatización y desarrollo de software en un entorno de trabajo unificado.

Tono

Profesional, estratégico, claro, innovador, seguro y humano. Comunicar beneficios concretos sin exageraciones. Usar frases breves, lenguaje directo y vocabulario empresarial accesible. Ascend debe transmitir precisión tecnológica, creatividad, confianza y capacidad de ejecución.

Propuesta

Transforma necesidades operativas y comerciales en soluciones digitales más rápidas, consistentes y escalables.

08 · Implementación

Orden y restricciones

Workspace y usuario → BrandAsset → BrandKit → BrandRule → WorkspacePreference → Product → CreativeAngle → CreativeRecipe → AdTemplate → AdProject → ProjectInputAsset.

RequisitoDetalle
WorkspaceResolver por UUID o slug; no asumir el primero salvo flag explícito.
UsuarioResolver por email para uploaded_by y created_by.
ArchivosCargar con django.core.files.File.
IdempotenciaUsar las claves naturales del manifest.
Dry runEjecutar en transacción y forzar rollback.
ResumenImprimir creados, actualizados, omitidos y errores.
